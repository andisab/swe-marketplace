# style-1 — Editorial Light

Publication voice: warm cream canvas, serif display headings over a humanist sans body, one warm coral accent used sparingly.

| File | What it is |
|---|---|
| `brand.md` | The brandbook: prose rules for every consumer, with a YAML precision layer loaders read first |
| `tokens.json` | Derived cache, regenerated by `scripts/load-style.js` when `brand.md` changes; never edit it |
| `assets/mark.svg`, `assets/mark-dark.svg` | A generic mark for light and dark backgrounds, so decks and sites have a logo slot filled until a real brand replaces it |
| `css/style-1.css` | Tokens as CSS variables (light, and dark via prefers-color-scheme or data-theme), base typography and the style's motif classes, for HTML pages that aren't built by a knowledgeware skill |

**The mark.** A page with a coral head rule and three text lines: the top-bar motif on a sheet of editorial copy.

**Use it.** Name the style in a request to any knowledgeware skill: "build the deck in style-1", "a knowledgebase site in the Editorial Light style". In your own HTML, link the stylesheet and use `.card`, `.kicker` and the other classes it defines:

```html
<link rel="stylesheet" href="css/style-1.css">
```
