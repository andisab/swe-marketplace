# style-4 — Warm Sage

Warm-gray canvas, serif headings over a sans body, a calm sage accent, and outlined rather than filled containers.

| File | What it is |
|---|---|
| `brand.md` | The brandbook: prose rules for every consumer, with a YAML precision layer loaders read first |
| `tokens.json` | Derived cache, regenerated by `scripts/load-style.js` when `brand.md` changes; never edit it |
| `assets/mark.svg`, `assets/mark-dark.svg` | A generic mark for light and dark backgrounds, so decks and sites have a logo slot filled until a real brand replaces it |
| `css/style-4.css` | Tokens as CSS variables (light, and dark via prefers-color-scheme or data-theme), base typography and the style's motif classes, for HTML pages that aren't built by a knowledgeware skill |

**The mark.** An outlined container holding one list item: a sage dot and a short line.

**Use it.** Name the style in a request to any knowledgeware skill: "build the deck in style-4", "a knowledgebase site in the Warm Sage style". In your own HTML, link the stylesheet and use `.card`, `.kicker` and the other classes it defines:

```html
<link rel="stylesheet" href="css/style-4.css">
```
