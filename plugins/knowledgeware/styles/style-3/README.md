# style-3 — Dark Precision

Dark-first canvas, bright violet accent, tight-tracked sans, and elevation by brightness instead of shadow.

| File | What it is |
|---|---|
| `brand.md` | The brandbook: prose rules for every consumer, with a YAML precision layer loaders read first |
| `tokens.json` | Derived cache, regenerated by `scripts/load-style.js` when `brand.md` changes; never edit it |
| `assets/mark.svg`, `assets/mark-dark.svg` | A generic mark for light and dark backgrounds, so decks and sites have a logo slot filled until a real brand replaces it |
| `css/style-3.css` | Tokens as CSS variables (dark, and light via prefers-color-scheme or data-theme), base typography and the style's motif classes, for HTML pages that aren't built by a knowledgeware skill |

**The mark.** Three bars stepping down in length and brightness beside a violet strip: elevation levels and the cover accent.

**Use it.** Name the style in a request to any knowledgeware skill: "build the deck in style-3", "a knowledgebase site in the Dark Precision style". In your own HTML, link the stylesheet and use `.card`, `.kicker` and the other classes it defines:

```html
<link rel="stylesheet" href="css/style-3.css">
```
