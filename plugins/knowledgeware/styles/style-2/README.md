# style-2 — Minimal

Pure white canvas, one geometric sans, one bright indigo accent under five percent of the page, and whitespace doing the rest.

| File | What it is |
|---|---|
| `brand.md` | The brandbook: prose rules for every consumer, with a YAML precision layer loaders read first |
| `tokens.json` | Derived cache, regenerated by `scripts/load-style.js` when `brand.md` changes; never edit it |
| `assets/mark.svg`, `assets/mark-dark.svg` | A generic mark for light and dark backgrounds, so decks and sites have a logo slot filled until a real brand replaces it |
| `css/style-2.css` | Tokens as CSS variables (light, and dark via prefers-color-scheme or data-theme), base typography and the style's motif classes, for HTML pages that aren't built by a knowledgeware skill |

**The mark.** A square outline with one indigo point inside it: almost nothing, placed deliberately.

**Use it.** Name the style in a request to any knowledgeware skill: "build the deck in style-2", "a knowledgebase site in the Minimal style". In your own HTML, link the stylesheet and use `.card`, `.kicker` and the other classes it defines:

```html
<link rel="stylesheet" href="css/style-2.css">
```
