# style-5 — Material Olive

A Material Design 3 palette on a pale cream-green canvas: olive primary, sage secondary, teal tertiary, soft shadows on rounded cards.

| File | What it is |
|---|---|
| `brand.md` | The brandbook: prose rules for every consumer, with a YAML precision layer loaders read first |
| `tokens.json` | Derived cache, regenerated by `scripts/load-style.js` when `brand.md` changes; never edit it |
| `assets/mark.svg`, `assets/mark-dark.svg` | A generic mark for light and dark backgrounds, so decks and sites have a logo slot filled until a real brand replaces it |
| `css/style-5.css` | Tokens as CSS variables (light, and dark via prefers-color-scheme or data-theme), base typography and the style's motif classes, for HTML pages that aren't built by a knowledgeware skill |

**The mark.** Three overlapping discs in olive, sage and teal: the tri-color accent system.

**Use it.** Name the style in a request to any knowledgeware skill: "build the deck in style-5", "a knowledgebase site in the Material Olive style". In your own HTML, link the stylesheet and use `.card`, `.kicker` and the other classes it defines:

```html
<link rel="stylesheet" href="css/style-5.css">
```
