Turning it on

Four steps per repository

  1. Add the workflow file

    Copy review.yml from the template repository.

  2. Set the reviewers

    CODEOWNERS decides who approves after the bot.

  3. Run it on one pull request

    Check the comments read well before the team sees them.

  4. Turn on the merge gate

    No merge without a human approval.

.github/workflows/review.yml
on: pull_request
jobs:
  review:
    uses: org/templates/review@v2
[click 1] … [click 4] The gate is the step people forget.
