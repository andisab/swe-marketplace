Managed settings

What each line buys

settings.jsonWhat it buys
permissions.defaultMode "ask"Every write and shell command waits for a person
permissions.deny ["Read(.env*)"]Secrets never enter the context, even when asked
sandbox.enabled trueThe OS blocks what a rule misses: files outside the repo, the network
allowManagedHooksOnly trueThe approval hooks are the only hooks that run
model "team-default"One model to budget for; overrides need a reason
cleanupPeriodDays 30Transcripts age out on the same schedule as logs
Read the right-hand column; the keys are there for the people who will copy them. [click 3] The sandbox is the line that matters: rules are advice to the model, the sandbox is enforced by the OS.
