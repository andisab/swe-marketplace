Four gates between a request and a merge

untrusted input
  1. before the model

    Input screening

    Strip secrets, flag instructions hidden in fetched pages.

  2. at each tool call

    Permission rules

    Allow, ask or deny, per tool and per path.

  3. deterministic

    Hooks

    Code that runs every time; the model can't talk its way past it.

  4. before merge

    Human review

    A code owner approves; the agent's approval never counts.
