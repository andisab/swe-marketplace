Blast radius

Four questions before an agent runs unattended

  1. 1

    What can it read?

    Everything the session can open is in the context.

    default: the repository
  2. 2

    What can it change?

    Writes outside the repo are the first thing to deny.

    default: the working tree
  3. 3

    What can it reach?

    Network access turns a bad read into a leak.

    default: allowlisted hosts
  4. 4

    What can it spend or ship?

    Credentials that deploy or pay need a person.

    default: none
